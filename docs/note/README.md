# note 入稿メモ（かきかたマスターの紹介記事）

連載「教室で使えるかもしれないもの作り」に載せる紹介記事の一式です。

```
docs/note/
├── kana-master-note-article.md   記事本文。そのまま note に貼れる形
├── images/                       実際に操作して撮った画面（28 点）
└── README.md                     このファイル
```

## 貼るまえに直すところ

- **連載番号**。タイトルの `#◯` を実際の番号に置きかえてください。前作からの
  通し番号が分からなかったので、推測で埋めずに残してあります。ここだけは
  自動で埋められません。
- タイトルそのものは案です。`「がっこう」が「がこう」になる子へ。おとと マスの
  ずれから 教える学習アプリ「ひらがな・カタカナ かきかたマスター」` に
  してあります。連載の並びを見て変えてください。

## note に貼る手順

1. 記事本文の 1 行目（`# 教室で使えるかもしれないもの作り #◯ …`）は、note の
   タイトル欄に入れます。本文には貼りません。
2. 2 行目以降を本文欄に貼ります。`##` の見出しはそのまま note の見出しになり、
   目次も自動で作られます。
3. 画像は貼りつけでは入らないので、`images/` の中身を 1 枚ずつ手で
   アップロードします。本文の `![…](images/…)` の位置に対応します。
   ファイル名の番号が本文に出てくる順です。
4. 画像の下に置いてある 1 行は、note のキャプション欄に移してください。
   本文にそのまま残すと、文章の流れから浮きます。
5. ハッシュタグ欄の候補。`#小学校` `#1年生` `#国語` `#ひらがな` `#特別支援教育`
   `#GIGAスクール` `#教育ICT` `#自作アプリ`

## 撮り直すときの手順

撮影用のシナリオは納品前に消してあります。もう一度撮るなら次の形です。

```bash
npm install
npm run build
node tools/serve.mjs 8788        # 別ターミナル
# http://127.0.0.1:8788/KANA_Master/
```

そのうえで、Playwright でブラウザを開いて操作します。今回引っかかったのは
次の 4 つなので、書き直すときも同じところに気をつけてください。

- **お祝いのモーダルを閉じてから次へ進む。** 「あめ」を集めて花丸が出たあと、
  「やったー！」を押さずに進むと、そのあとの全画面にお祝いがかぶさります。
  最初はこれに気づかず、10 枚以上を撮り直しました
- **トロフィーのボタンは文字で探せない。** ボタンの中身がはんこの数（`1`）なので、
  文字で照合すると数字にしか当たりません。読みあげ用の名前
  （`ごほうびの はんこ ずかん を ひらく`）で探してください。空白が入っています
- **ちからだめしで押すボタンは、こたえの札だけに絞る。** 画面じゅうのボタンから
  「こたえ以外」を選ぶと、ヘッダーのはんこの数を押してモーダルが開きます
- **こたえあわせは 1 秒ちょっとで消える。** 押してから 600ms 前後で撮らないと、
  もう次の問題に進んでいます

字を書くところは、`globalThis.KANJIVG_KANA` のストロークを SVG のパスとして
サンプリングし、キャンバスの上を実際のポインタ操作でなぞりました。合成では
ないので、採点も赤ペンもアプリが本当に返した結果です。ゆらぎを混ぜる量で
点数が変わります。今回は自力書き 1 回目に少し大きめのゆらぎを入れて 85 点
（直すところ 2 つ）、2 回目 3 回目はほぼお手本どおりで 100 点でした。

## 撮っているあいだに気づいたこと

**動かない機能は見つかりませんでした。** ホーム、かく（4 だんかいと採点と赤ペン）、
よむ（6 コース）、とくべつ（6 ユニットと 4 つの出題のかたち）、ずかん、しりとり、
ちからだめし（2 課題と結果）、はんこずかん、大人向けのまとめまで通しています。

1 点だけ記録として。撮影した環境は Google Fonts に届かないネットワークでしたが、
`fonts.googleapis.com` が落ちても画面はすべて出て、押せるボタンも欠けません
でした。書体が予備のものに変わるだけです。記事の管理者向けの節で「ふさがれて
いても字の形がすこし変わるだけ」と書いているのは、この実測にもとづいています。

## 文体について踏襲したこと

連載の執筆プロンプトの指定にそろえてあります。書き足すときも崩さないでください。

- 太字・斜体・表を使っていません。`→` `／` `：` `▲` `▶` も 0 件です
- 箇条書きは導入手順と使い方のガイドだけです。ほかは文章で書いています
- 絵文字は見出しだけに入れています
- デプロイ、ローカルストレージ、SRS といった言葉は出さず、「公開の設定」
  「その端末の中にだけ残ります」「日をあけてもういちど出ます」と言いかえています
- 見出しは基本の 6 本に、目玉が収まらないぶんとして
  `💡 まん中に すえたのは、おとと マスの ずれ` と
  `🤝 2分の ちからだめしで、その子に あわせて 変わる` を 2 本足しました
- 本文は約 8,800 字です

**教室での出来事は実体験として書いていません。** 作者の実践記録ではないので、
「使ってみたら子どもたちが〜」は入れず、「こうなればいいと思って作った」
「〜だと思います」までにとどめています。実際の授業の様子は、書き手のほうで
足してください。効果も言い切っていません。
